AI HR ASSISTANT v8.8.242 — PROVIDER SWITCH GUIDE
==================================================
Made as a separate release from v8.8.241. No UI/RAG/HR business logic changes.

In your existing .env, ADD these lines (do not replace the file or share secrets):

SMART_AI_LLM_MODE=local
SMART_AI_GROQ_API_KEY=
SMART_AI_GROQ_MODEL=qwen/qwen3.8-27b
SMART_AI_GROQ_TIMEOUT_SECONDS=25

MODE: local = only Ollama (default); groq = only Groq;
      hybrid = Groq first then Ollama on error/missing key/timeout.
Switch the single SMART_AI_LLM_MODE value as needed. The Groq secret
can also be provided via GROQ_API_KEY. Restart Streamlit/Python after edits.

Cloud warning: Groq and Hybrid send authorized company evidence and the
user question in the prompt to Groq. Approval required for HR data use.
The Groq Qwen3.8 model is Preview; verify access, pricing and quota.
No Groq SDK is needed. Requests use a fixed official HTTPS endpoint.
